# Публикация игры с облачным ИИ на Cloudflare (бесплатно)

Получится одна ссылка вида `https://space-between-memories.<ваше-имя>.workers.dev`. По ней игра открывается у кого угодно, в том числе у жюри, без Claude и без установки.

Как это устроено:
- Игра и сервер-посредник работают в одном Cloudflare Worker.
- Ключ ИИ хранится **только в секретах Cloudflare**. В HTML его нет, через «Просмотр кода» его не увидеть.
- Если ИИ недоступен (лимит, нет связи), игра сама переходит на встроенную нейросеть.

Займёт 10–15 минут.

---

## 1. Что понадобится

1. **Node.js** версии LTS: https://nodejs.org → скачать → установить «Далее-Далее».
2. **Аккаунт Cloudflare** (бесплатный): https://dash.cloudflare.com/sign-up
3. **Ключ ИИ** — один из двух.

### Вариант A — Google Gemini (рекомендую для хакатона: есть бесплатный лимит, карта не нужна)
1. Открой https://aistudio.google.com/apikey и войди Google-аккаунтом.
2. Нажми **Create API key** и скопируй ключ. Он начинается на `AIza…`.
3. Важно: на бесплатном уровне Google может использовать присланные данные для улучшения своих сервисов. Перед загрузкой фото людей прочитай условия на странице Gemini API.

### Вариант B — Claude (Anthropic): лучше по качеству, но платно
1. Открой https://console.anthropic.com → **API Keys** → **Create Key**. Ключ начинается на `sk-ant-…`.
2. В **Billing → Limits** поставь месячный лимит трат, например $5.
3. В файле `wrangler.toml` поменяй строку `PROVIDER = "gemini"` на `PROVIDER = "anthropic"`.

> Ключ никому не отправляй, в том числе мне. Ты сам вставишь его в Cloudflare на шаге 4.

## 2. Открой папку проекта в терминале

Распакуй архив `space-between-memories-cloudflare.zip`. Открой папку, где лежит `wrangler.toml`.

- **Windows:** кликни по адресной строке проводника, напиши `cmd` и нажми Enter.
- **macOS:** правый клик по папке → «Новый терминал по адресу папки».

## 3. Войди в Cloudflare и опубликуй

```
npx wrangler login
```
Откроется браузер — нажми **Allow**. Если npx спросит, устанавливать ли wrangler, ответь `y`.

```
npx wrangler deploy
```
В конце появится адрес `https://space-between-memories.….workers.dev` — сохрани его.

## 4. Добавь ключ в секреты (не в HTML!)

Для Gemini:
```
npx wrangler secret put GEMINI_API_KEY
```
Для Claude:
```
npx wrangler secret put ANTHROPIC_API_KEY
```
Вставь ключ (символы при вводе не видны, это нормально) и нажми Enter.

## 5. Проверь

1. Открой в браузере `https://…workers.dev/api/health`. Должно быть `{"ok":true,"provider":"gemini",…}`. Если там `"API key secret is not set"`, повтори шаг 4.
2. Открой ссылку на игру **в режиме инкогнито**. Нажми Esc — в меню должна быть строка «🤖 Облачный ИИ подключён».
3. Создай воспоминание: фото места, рассказ, фото персонажа. При сборке должна быть строка «Облачный ИИ изучил фото и рассказ».
4. Войди в мир, вернись в Уровень 0, открой раму и нажми «ПЕРЕСОБРАТЬ».

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| `/api/health` пишет про отсутствие ключа | повтори шаг 4 |
| «Облачный ИИ не ответил (… model … not found)» | модель переименовали. Впиши актуальное имя в `MODEL = "…"` в `wrangler.toml` (список моделей есть в Google AI Studio или Anthropic Console) и снова выполни `npx wrangler deploy` |
| «… quota / rate limit …» | закончился бесплатный лимит провайдера или сработал наш лимит (`RATE_LIMIT`, по умолчанию 12 запросов за 10 минут с одного адреса). Игра продолжает работать на встроенной нейросети |
| Хочу открыть игру просто файлом (из ZIP), но с облачным ИИ | пришли мне адрес `…workers.dev` — я впишу его в `index.html`. Ключ при этом в файл не попадает |

## Обновить игру

Положи новый `index.html` в папку `public/` и снова выполни `npx wrangler deploy`.

## Безопасность

- Ключ виден только Cloudflare. Сервер не возвращает его ни в каких ответах (это проверено тестом `node test/worker.test.mjs`).
- Сервер принимает только картинки (jpeg, png, webp) и текст, с ограничением размера и числа запросов, и только с вашего домена или из локального файла.
- Когда хакатон закончится, ключ можно удалить у провайдера. Игра продолжит работать на встроенной нейросети.
